# 素材放置说明

游戏现在支持每段剧情自动切换图片或视频。

把素材放在本文件夹，并使用以下文件名即可自动显示：

- `milk-tea-shop.jpg`：奶茶店环境图
- `ruoxi-working.jpg`：若溪在柜台打工图
- `ruoxi-serving.mp4`：若溪送餐视频
- `spilled-milk-tea.jpg`：奶茶洒在电脑上的图
- `ruoxi-apology.jpg`：若溪道歉图

如果你想改文件名或增加更多剧情，编辑上一级的 `script.js`，修改每个 scene 里的 `media.src`、`media.type`、`media.caption` 即可。
